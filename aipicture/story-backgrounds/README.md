# 《千桥协议》章节背景生成记录

这八张场景图使用 Codex 内置 ImageGen 生成，运行时转换为 1672×941 的 WebP。共同提示词约束为：精致的日系视觉小说背景、宽屏 16:9 构图、为画面中右部角色立绘保留平静空间、底部约 38% 使用较暗且低细节的区域承接对话框、场景内无人、无可读文字、无品牌标志、无界面、无水印。

各图在共同提示词上增加以下场景描述：

- `prologue-station.webp`：蓝金色的千桥总站大厅，弧形玻璃、远处桥群、夜间到站灯与安静检票台。
- `association-open-day.webp`：百模协会开放日大厅，模型、数据集和工具工坊以展台与档案架相连，暖色午后光。
- `laurel-theatre.webp`：月桂审议所在的旧剧院，空舞台、评审席、档案灯和深红帷幕，克制的金色照明。
- `bridges-night.webp`：千桥事故夜，交叠桥梁、故障信号灯、雾与封锁线，蓝橙色紧张照明。
- `three-harbors.webp`：清晨雾中的三座代码港，公开变更簿、流水线坞站与镜像钟楼由水道相连。
- `open-dome-hearing.webp`：木质开放议事厅与玻璃穹顶围绕圆形证据桌相接，上午天光，公开席和审议席各有入口。
- `protocol-composition.webp`：夜间档案馆的协议组合室，三层同心机械桌、卷宗、权限钥匙和桥形窗景。
- `six-endings.webp`：日出时的千桥观景台，多种桥形通往同一座城市，金蓝晨光，适合结局卡片覆盖。

原始生成结果由 Codex ImageGen 保存；仓库中的 WebP 是插件构建实际使用的版本。背景没有合成人物，角色仍使用项目已有立绘。
